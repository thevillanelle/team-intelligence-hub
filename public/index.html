✉️ Option A — Email your Admin EASIEST

Step 1. Make your changes — edit the team wiki docs above or use the admin tools.
Step 2. Click "Email Changes to Admin" in the Tools tab.
Step 3. Your Mail app opens — pre-addressed, subject pre-filled. Hit send.
Step 4. Your admin opens AI assistant and the site updates in ~60 seconds. Done!
✅ No technical setup needed. Works for everyone.

☁️ Option B — Push via AI assistant INSTANT

Step 1. Make your changes in the team wiki docs or using the admin tools.
Step 2. Open AI assistant on your Mac.
Step 3. Type: "sync the Skills Hub"
Step 4. AI assistant pushes changes to GitHub. Site updates in ~60 seconds. No waiting on anyone!
Requires: GitHub MCP + team wiki MCP servers enabled in AI assistant Settings → MCP.
Contact your admin if you need help getting those set up.
